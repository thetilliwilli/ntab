Every new tab opens a clean home screen with your favorite sites and a fast plain-text notepad with tabs, like Notepad++.

Notes are ordinary text files in a folder you choose on your computer. Every change is saved as you type, and your open tabs come back after a browser restart.

HOME SCREEN
• Big tiles for your sites and the notepad, plus the same icons in a slim sidebar
• Add a site with the "+" tile: paste the address, the name fills in by itself
• Every new tab starts here, so your notes never pop up on screen by themselves (handy when sharing your screen)
• Site icons from Chrome's own cache, or upload your own
• Hover a sidebar icon to see its full name and address
• Edit the list in a simple form or as raw JSON; it follows your Chrome profile through Chrome sync

NOTEPAD
• Tabs: double-click the empty tab bar for a new note, drag to reorder, double-click to rename
• Any file name and extension: note.txt, todo.md, log…
• Saves as you type, no save button; unsaved text survives a crash or a closed tab
• Line numbers, word wrap, font size, configurable Tab width
• Status bar with line, column, length and save state
• File list with filter: open, delete or switch the notes folder
• Right-click a tab to delete its file
• Each browser tab keeps its own set of open notes; edits to the same file sync between them
• Light, dark or automatic theme

PRIVACY
• No account, no servers, no tracking, no network requests
• Your notes stay in the folder you picked
• Permissions: "storage" for settings and your site list, "favicon" to show site icons from Chrome's local cache

WHAT'S NEW
• The home screen is split into Apps (the notepad) and Links
• The "+" tile adds a site in a small dialog: address, name, icon, new tab

Note: only one extension can replace the new tab page. If another one already does, Chrome will ask which to keep.
