Every new tab opens a clean home screen with your favorite sites and three small tools: a fast plain-text notepad with tabs (like Notepad++), an activity tracker and a task board.

Everything is saved in your browser as you type, nothing to set up. Export a backup to one JSON file whenever you like; NTab reminds you once a week.

HOME SCREEN
• Big tiles for your apps and sites, plus the same icons in a slim sidebar
• Add a site with the "+" tile: paste the address, the name fills in by itself
• Every new tab starts here, so your notes never pop up on screen by themselves (handy when sharing your screen)
• Site icons from Chrome's own cache, or upload your own
• Embed all site icons in your data with one click, so a backup carries them
• Hover a sidebar icon to see its full name and address
• Right-click a tile to edit or delete it
• Edit the whole list in a simple form or as raw JSON

REQUEST TILES
• A tile can send an HTTP request: URL, method, headers, body
• One click shows the answer in a window: status, time, headers, the body as text or formatted JSON
• Pick out what you need with a small JavaScript function of your own, e.g. w => w.json.ip or w => w.document.querySelector("table").outerHTML, shown as text or HTML
• Repeat, copy the answer; handy for health checks, your public IP, small APIs

NOTEPAD
• Tabs: double-click the empty tab bar for a new note, drag to reorder, double-click to rename
• Any name: todo, todo.md, log.txt…
• Saves as you type, no save button
• Download a note as a file named like the note
• Line numbers, word wrap, font size, configurable Tab width
• Status bar with line, column, length and save state
• List of all notes with filter: open or delete
• Right-click a tab to download or delete the note
• Each browser tab keeps its own set of open notes; edits to the same note sync between them

TRACKER
• One tap logs that something happened: woke up, workout, coffee, called mom…
• Your own event types with an emoji
• Activities with a start and a finish: a live timer and a growing bar while they run
• Today's count and last time on every tile
• Day log: fix a start or finish time, delete, undo
• Clear the whole log in one go, your event types stay

TASK BOARD
• Columns New, Planned, Work, Hold, Done
• Tasks with a name and a description
• Drag cards between columns, or change the status in the task window

DATA
• Export everything (notes, tracker, board, sites, settings) as one JSON backup, import it on another computer
• Importing only adds what is missing, it never deletes or overwrites anything
• Import text files as notes
• Delete all data for a fresh start
• A gentle reminder on the home screen when the last backup is a week old

• Light, dark or automatic theme
• Also runs as a web app (works offline) in any browser: thetilliwilli.github.io/ntab

PRIVACY
• No account, no servers, no tracking; no network requests except the request tiles you create
• Your notes, events and tasks stay in your browser (and in the backups you export)
• One permission: "favicon", to show site icons from Chrome's local cache. Access to a site is asked only when one of your request tiles needs it, for that site only

WHAT'S NEW
• NTab as a web app: thetilliwilli.github.io/ntab
• Tracker: log events with one tap, time activities
• Task board with New / Planned / Work / Hold / Done
• Request tiles: send an HTTP request, see the answer
• Everything is now kept in the browser, no folder to choose; backup export and import (adds, never deletes)
• Your old note files: Data → Import text files. The site list starts over from the defaults

Note: only one extension can replace the new tab page. If another one already does, Chrome will ask which to keep.
